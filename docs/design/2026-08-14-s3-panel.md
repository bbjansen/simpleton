# S3 object-browser client panel

Status: implemented
Date: 2026-08-14

## Goal

Add an S3 (and S3-compatible, e.g. MinIO) object-browser GUI client, mirroring the existing
`SimpletonSQL` driver library and SQL client panel. A user saves an `.s3` connection in Data
Connections, launches it, browses buckets and prefixes with folder-style navigation, and can
download, upload, delete, and copy a presigned URL for objects.

## Architecture

Same three-layer shape as the SQL client:

1. **`SimpletonS3` library target** — isolates the AWS SDK (Soto) from `SimpletonCore` and the app.
   - `S3Backend` protocol seam (mirrors `SQLDriver`): `connect`, `listBuckets`, `list`,
     `download`, `upload`, `delete`, `presignGetURL`, `close`. All async; every failure is mapped
     to `S3Error` so no raw Soto/NIO error escapes.
   - Pure `Sendable` model: `S3Bucket`, `S3Object`, `S3ListPage`, plus a `humanSize` formatter and
     an `S3Error` enum (`auth`, `notFound`, `connectionFailed`, `unsupported`).
   - `SotoS3Backend` concrete impl over `SotoS3` (Soto pinned `exact: "7.15.0"`). Builds an
     `AWSClient(credentialProvider: .static(...))` + `S3(client:region:endpoint:options:)`.
   - `S3BackendFactory.make(_:secret:)` switches on `ConnectionKind`; non-`.s3` throws
     `.unsupported`.

2. **CoreChecks suite** — `S3DriverChecks.swift`: pure-model checks (isPrefix, `humanSize`,
   `S3ListPage` shape), factory mapping (`.s3` → `SotoS3Backend`, `.postgres` → throws
   `.unsupported`), and an env-gated live `listBuckets` against MinIO (`SIMPLETON_S3_TEST_ENDPOINT`
   / `_KEY` / `_SECRET`), skipped with a printed note otherwise.

3. **GUI panel** — `S3PanelView` + `S3PanelModel`, mirroring the SQL panel: own connection `Picker`
   filtering `.s3`, `ClientPanelScaffold`, `themedGlass(DT.surface)`, pending-open consume via
   `PendingClientOpen.shared.take(for: PanelProfile.PanelID.s3)`. Registered as a drawer panel
   (`prefersDrawer: true`) and mapped in `GUIClientRegistry` for `[.s3]`.

## Config & secrets

- Non-secret config on `Connection.params`: `endpoint` (optional; AWS default when blank),
  `region` (default `us-east-1`), `bucket` (optional default), `pathStyle` (bool; default true for
  MinIO/S3-compatible). `Connection.host` is `nil` for `.s3` (endpoint lives in params).
- Secrets in the Keychain via `CredentialStore`: `accessKey` + `secretKey` on `ConnectionSecret`.
- Path-style: Soto uses path-style by default when a custom `endpoint` is set; `pathStyle == false`
  adds the `.s3ForceVirtualHost` service option.

## Model

- `S3Bucket { name, creationDate? }`
- `S3Object { key, size, lastModified?, etag?, isPrefix }` (`isPrefix` marks a folder row)
- `S3ListPage { objects, commonPrefixes, nextToken? }` (paged via continuation token)

## S3 operations

`listBuckets`, `list(bucket:prefix:continuationToken:)` (delimiter `/` for folders),
`download(bucket:key:)` → `Data`, `upload(bucket:key:data:)`, `delete(bucket:key:)`,
`presignGetURL(bucket:key:expires:)`. `close()` calls `try await client.shutdown()` exactly once.

## MVP scope

Bucket list → prefix browse (breadcrumb + up, folder rows navigate) → object table (name, human
size, modified) → Download (`NSSavePanel`), Upload (`NSOpenPanel`), Delete (confirm), Copy URL
(presigned, 1h). Real Soto calls; no mocks in the panel.

## Verification

`swift build`; `swift run CoreChecks` (pure + factory always run; live test env-gated);
`swift format lint --recursive --parallel --strict Sources Tests`. Live browse verified against a
MinIO endpoint when the env vars are set.

## Sandbox

The app is unsandboxed (no `.entitlements` / `com.apple.security.app-sandbox`), so outgoing S3
network needs no entitlement change.
